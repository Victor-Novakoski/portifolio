# 012. Revelação entra nos projetos

- **Data:** 12/11/2026
- **Status:** ativa

## Contexto

O Revelação é um jogo de terror no navegador que o Victor fez por diversão, não como projeto de carreira. Mesmo assim mostra Three.js, shaders e uma CLI em Go.

## Decisão

O Revelação ganha um card de "item raro" em Projetos, ocupando a linha inteira no desktop, com print e link para o código.

## Consequência

O card fica, mas o Revelação não entra no currículo nem nas prioridades de carreira.
