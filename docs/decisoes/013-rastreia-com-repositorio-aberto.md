# 013. Rastreia com repositório aberto

- **Data:** 12/11/2026
- **Status:** ativa (substitui a 010)

## Contexto

Sem código público, o projeto principal não tinha prova (010). No currículo, o link do Rastreia passa a apontar para o portfólio.

## Decisão

O repositório do Rastreia vai ser aberto. O card do portfólio troca "Código sob pedido" pelo link do código e passa a ter um endereço próprio que o currículo possa citar.

## Consequência

Enquanto o repositório não abre, o site ainda mostra "Código sob pedido". A troca está numa issue.
