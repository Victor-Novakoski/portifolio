# CLAUDE.md

Portfólio do Victor Novakoski, desenvolvedor full stack (Go + React). Tema "Forja do Caçador": uma tela de título em canvas, desafios técnicos como lutas contra chefes e o mini game Caça-bugs, sem esconder o conteúdo de quem só quer ler.

No ar: https://portifolio-victor-novakoski.vercel.app

## Stack

React 19, TypeScript e Vite 6, com CSS puro (`src/styles/forja.css`) e canvas 2D. Sem framework de UI, motor de jogo, biblioteca de animação ou backend. Deploy estático na Vercel. Gerenciador: yarn 1.

## Comandos

```bash
yarn install --frozen-lockfile
yarn dev        # http://localhost:5173 (?volta=1 simula quem volta)
yarn lint       # eslint
yarn build      # typecheck (tsc nos dois tsconfig) + vite build
```

Não há testes automatizados (ver docs/decisoes/011). A CI roda lint e build em todo PR.

## Como se orientar

- Comece por [docs/INDEX.md](docs/INDEX.md) e abra só o que a tarefa pede.
- Módulos com regras próprias: `src/data/`, `src/game/`, `src/scene/` (cada um com o seu CLAUDE.md).
- O porquê das escolhas está em [docs/decisoes/](docs/decisoes/).

## Regras gerais

- Conteúdo primeiro: nome, cargo, stack e currículo aparecem no primeiro quadro a 390 px, sem depender de animação. Todo jogo tem atalho ("Ler sem lutar", fechar o mini game).
- Movimento reduzido: com `prefers-reduced-motion`, nada anima, e o site continua completo. O botão Pausar do cabeçalho para tudo (`runtime.setPaused`).
- Nunca trocar nem esconder o cursor nativo. Efeitos de mouse com `pointer-events: none`, desligados no toque.
- Todo `useEffect` que cria listener, observer, timer ou `requestAnimationFrame` desfaz tudo no cleanup. O StrictMode roda os efeitos duas vezes no dev e esconde vazamentos.
- `localStorage` e `sessionStorage` só por `src/lib/storage.ts` (`safeGet`/`safeSet`): em aba anônima eles lançam erro.
- Alvos de toque de 44 px, foco visível e tudo usável pelo teclado.
- Imports com o alias `@/` (aponta para `src/`).
- Textos do site em português do Brasil. Código e identificadores em inglês; comentários em português.
- Dados pessoais e de trabalho: ver `src/data/CLAUDE.md` (sigilo da Galileu, nada de número inventado).
